## 1. 全局配色体系

### 1.1 主色（品牌深蓝色阶）
| Token | Hex | 含义与典型用法 |
|------|-----|----------------|
| `brand-50` | #EFF6FF | 最浅蓝底，按钮/标签底色（如 `bg-brand-50`） |
| `brand-100` | #DBEAFE | 卡片提示底、tag 底 |
| `brand-200` | #BFDBFE | 边框/分割 |
| `brand-300` | #93C5FD | hover 边框 |
| `brand-500` | #4A90E2 | 强调主色（图表 line/bar） |
| `brand-600` | #2E74B5 | 标题点缀竖条、链接、主按钮（`bg-brand-600`） |
| `brand-700` | #1F497D | 数字强调、深色按钮 hover、登录页深蓝 |
| `accent` | #4A90E2 | focus 边框 |

### 1.2 状态色
| Token | Hex | 含义 |
|------|-----|------|
| `success` | #16A34A | 已完成、A级、通过 |
| `warning` | #F59E0B | 关注、B级、待复核 |
| `danger` | #DC2626 | 危险、D级、熔断 |
| `gold` | #D97706 | 双轨融合标识（含金色高光） |

### 1.3 中性色
| Token | Hex | 含义 |
|------|-----|------|
| `ink` | #1E293B | 主文字 |
| `muted` | #64748B | 弱化文字 |
| `bg` | #F8FAFC | 整体背景 / 表头底 |
| `border` | #E2E8F0 | 通用边框、分割线 |
| 辅助灰 | #CBD5E1 / #94A3B8 / #F1F5F9 | 图表 axisLine/splitLine |

### 1.4 用色规则
- **D 级熔断**强制 `danger` 色 + 红色背景 `bg-danger/5` + `breathe` 呼吸动效。
- **双轨融合等级**强制 `gold` + `bg-gradient-to-br from-yellow-50 to-amber-100` + `glow-gold` 光晕。
- **A/AA/AAA** 级用 `success`；BBB/BB/B 用 `warning`；CCC/CC/C 用 orange-600；D 用 `danger`。
- 透明叠加：状态色统一用 `/5`（5% 底）、`/10`、`/15`、`/30`（边）四档。

## 2. 字体规范

### 2.1 字体家族
- 中文：系统默认（PingFang SC / 微软雅黑），Tailwind 默认 sans。
- 数字 / 等宽：自定义 utility class `.num`（实测优先 `font-feature-settings: "tnum"` + 等宽，做 KPI 数字对齐）。
- 英文：Tailwind 默认 sans。

### 2.2 字号层级
| 用途 | Tailwind | 示例 |
|------|----------|------|
| 页大标题 H1 | `text-xl` (20px) `font-semibold` | "工作台首页" |
| 报告主标题 | `text-2xl font-bold` | "报告头主体名称" |
| 模块标题 H2 | `text-base font-semibold` | "今日待办" |
| 子模块标题 H3 | `text-sm font-semibold` | 卡片小标题 |
| 正文 | `text-sm` (14px) | 表格 / 段落 |
| 辅助/标签 | `text-xs` (12px) | 按钮、说明 |
| 小型说明 | `text-[10px]` / `text-[11px]` | tag、来源 |
| 大数字 | `num text-2xl/3xl font-bold` | KPI、评分 |

### 2.3 字重 / 行高
- 标题：`font-semibold` 或 `font-bold`。
- 正文：默认（400），重点用 `font-medium`。
- 行高：段落 `leading-relaxed`、紧凑列表 `leading-snug`。
- 对齐：表格混合左/中/右；金额数字右对齐 + `num`。

## 3. 组件库规范

### 3.1 按钮
| 类型 | Class 串 |
|------|---------|
| 主按钮 | `text-xs px-3 py-1.5 bg-brand-600 text-white rounded-md hover:bg-brand-700` |
| 次按钮 | `text-xs px-3 py-1.5 border border-border rounded-md hover:bg-bg` |
| 危险按钮 | `text-xs px-3 py-1.5 bg-danger text-white rounded hover:bg-red-700` |
| 成功按钮 | `text-xs px-3 py-1.5 bg-success text-white rounded hover:bg-green-700` |
| 文字链接 | `text-xs text-brand-600 hover:underline` |

### 3.2 表单
- 输入框：`mt-1 block w-full px-3 py-2 border border-border rounded-md focus:outline-none focus:border-accent text-sm`
- 标签：`text-xs text-muted` + 必填 `<span class="text-danger">*</span>`
- 下拉、textarea 同上。

### 3.3 卡片
- 标准卡：`bg-white rounded-lg shadow-card p-5/6` （`shadow-card` = 轻阴影）
- 顶头点缀：`<span class="w-1 h-5 bg-brand-600 rounded"></span>` 紧贴 H 标题
- 双轨融合卡：`border-2 border-gold rounded-lg p-4 text-center bg-gradient-to-br from-yellow-50 to-amber-100 glow-gold`

### 3.4 表格
- 容器：`overflow-x-auto border border-border rounded-lg`
- thead 样式：`tr.th text-left` （`.th` 自定义：底色 `bg-bg`、`text-xs text-muted` `font-semibold`）
- tbody：`divide-y divide-border`、行 hover：`hover:bg-bg`
- D 级行高亮：`bg-danger/5`

### 3.5 弹窗（modal）
- 由 `openModal({title,content,footer,width})` 渲染：默认 `max-w-2xl`，可选 `max-w-md/lg/xl`。
- 遮罩 + 居中 + ESC/点击关闭 + 关闭按钮在右上。
- 确认对话框 `confirmDialog({title,content,okText,cancelText,danger})` 返回 Promise<boolean>。

### 3.6 状态徽章 gradeBadge(grade, opts?)
- 入参：等级字符串（AAA/AA+/A/B/C/D/NR…）
- 输出：`<span class="...">${grade}</span>`，颜色与 1.2 用色规则一致；`opts.large=true` 时变大；`opts.withFuse=true` 时附 D 级熔断红点 / 加上 `breathe` 动效。

### 3.7 toast 与 confirm
- `toast(msg, type='info', duration=2000)`：右上角浮层；type=success/info/warning/danger。
- 5 类预警颜色映射：red/yellow/blue 映射到 danger/warning/brand。

### 3.8 步骤指示器（五步闭环）
- `step-indicator` 容器横向均分；圆 `w-10 h-10 rounded-full border-2 flex items-center justify-center`
- 已完成：`bg-success border-success` + ✓
- 当前：`bg-brand-600 ring-4 ring-brand-100`
- 未完成：`bg-white text-muted border-border`

### 3.9 顶部导航 Layout（layout.js mountLayout(active, render)）
- 左侧侧边栏 `w-56`（窄屏可折叠）：导航列表，激活项 `bg-brand-50 text-brand-700 font-medium border-l-2 border-brand-600`。
- 顶部 Header（高 56px）：左 logo + breadcrumb / 右 用户头像、通知、AI 助手入口。
- 主内容区 `flex-1 px-6 py-5 max-w-[1480px]` 居中。

## 4. 布局规范

### 4.1 栅格
- Tailwind 默认 12 栅格；常见：`grid-cols-1 md:grid-cols-2 lg:grid-cols-3/4/5`
- 报告 KPI：`grid-cols-2 md:grid-cols-4/5 gap-3/4`

### 4.2 间距
- 页面 padding：`px-6 py-5`
- section 间隔：`mb-5` / `space-y-5`
- 卡内 padding：`p-4 / p-5 / p-6`
- 间隙：gap-3 / gap-4 / gap-5（≈12/16/20px）

### 4.3 响应式
- PC 优先；断点 md=768、lg=1024。
- 内容最大宽：`max-w-[1480px]`（报告详情页）。
- 移动可降级，不强制 100% 还原。

### 4.4 报告详情页布局
- 顶 Header（含 breadcrumb + 操作） + 元数据条
- 左 TOC `w-56 sticky top-[5.75rem]`
- 主区 `flex-1 px-8 py-6 space-y-6 min-w-0 max-w-[calc(100%-14rem)]`
- 14 个 section（sec-1~sec-14）

## 5. 交互规范

### 5.1 hover/active
- 卡片：`lift` 自定义类（轻微上浮 + 阴影增强）
- 按钮：颜色加深一档
- 链接：`hover:underline`

### 5.2 动效
- `pulse-dot` 圆点呼吸动画（D 级 / 紧急徽章）
- `breathe` 整体呼吸（D 级熔断警报区块）
- `fade-in-up` 入场（首屏卡片）
- `glow-gold` 金色光晕（双轨融合）
- `grad-text` 渐变文字（404、欢迎语姓名）
- `grad-deep-blue` 渐变深蓝背景（隐私计算盒、计费盒、登录页左侧）

### 5.3 滚动锚点
- 报告详情页 TOC scrollspy：`activeToc` 切换 `toc-active` 与 `toc-item` 类，并更新进度条。

### 5.4 通知
- 右上角浮层 toast，2 秒自动消失，可叠加（栈式）。
