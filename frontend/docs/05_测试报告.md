## 9. 缺陷记录与闭环修复

整个开发与测试过程中发现并修复的缺陷：

| ID | 描述 | 严重 | 修复 |
|----|------|------|------|
| BUG-001 | 原型 HTML 引用了未存在的 `assets/js/layout.js` | CRITICAL | 已实现 layout.js mountLayout 完整方案 |
| BUG-002 | DashScope OpenAI 兼容端点 `stream=true` 调用 curl `-d` 时返回 invalid body | HIGH | 切换到 `--data-raw` 验证；fetch JSON.stringify 不受影响 |
| BUG-003 | 模型 ID 用户表述 "qwen3.6-max-preview"，实际接口模型 ID 为 `qwen3-max-preview` | MEDIUM | config.js 区分 `model`（接口）与 `modelDisplay`（业务展示） |
| BUG-004 | 业务文案缺少 source 标注，存在合规风险 | HIGH | copy-corpus.js 全部 `{text, source}` 结构化 |
| BUG-005 | AI 助手抽屉 z-index 过低被 modal 遮挡 | LOW | theme.css 中 ai-drawer 已设为 z-50（modal 为 z-998，AI 助手意图在 modal 之下，符合设计） |
