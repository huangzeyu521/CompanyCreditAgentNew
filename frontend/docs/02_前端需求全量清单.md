## C. 大模型双增强需求（核心）

### C-01 思考过程可视化
- 流式输出阶段化展示，预定义 6 个标准化思考步骤：
  1. 解析用户意图与任务边界
  2. 检索远东评级方法学与制度
  3. 拉取被评主体公共信用画像（八大维度）
  4. 跨域风险翻译 / PD-LGD 映射
  5. 熔断红线与三级审核合规校验
  6. 输出结论与引用溯源
- UI 形态：右侧抽屉 / 内联区，左侧"思考链"时间轴 + 进度环；右侧最终输出。
- 流式文字打字效果；阶段切换时步骤勾选 ✓ + 进度条推进；异常态降级为错误卡 + 重试按钮。

### C-02 内置提示词库（系统提示词工程）
为 12 个调用场景预置专业级 System Prompt：
1. 评级初稿撰写（按方法学版本）
2. 公共信用八大维度归因解读
3. 跨域风险翻译（公共扣分→PD/LGD）
4. 熔断校验解释（命中 D 级原因 + 处置建议）
5. 三级审核差异检测（建议）
6. 信评委议程包摘要
7. 跟踪 21 类重大事项识别
8. 同业对比解读
9. 信用修复路径建议
10. 监管报送底稿初稿
11. 审计追溯问答
12. 通用知识库 RAG 问答
- 提示词模板内嵌：法定来源、合规红线、ABCD ↔ AAA-C 映射、参考国标，以及"必须可溯源、不可越界"。
- API：`qwen3.6-max-preview`（dashscope 兼容协议），Streaming SSE。

### C-03 异常处理
- 网络/超时：自动重试 2 次；失败给 toast 提示并提供"重试"按钮。
- 越界（机密外发）：前端 DLP 词典拦截（如不出现 USCC、未发表的报告全文）。
- API key 缺失：友好提示 + 跳转配置。

## D. 文案合规需求

- 所有页面标题、tab 名称、KPI 标签、按钮文字、表单 label、提示文案、合规声明、报告各章标题与正文、归因维度、熔断条件等，均**必须来自 sfecr 文件夹的提取文案库**（见 frontend/data/copy.js）。
- 文案分类：评级业务全流程文案、合规与制度文案、评级方法术语、政策与国标、合规声明文案、监管报送模板、ESG 维度文案、八大维度术语、评级等级释义。
- 每条文案必须标注 `source: 文件路径`。
- 校验：构建期校验所有文案均在文案库内可查到；不在库的拒绝合并。
